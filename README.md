# Titanic Survival Prediction

This project uses the **Titanic dataset** to build a machine learning classification model that predicts whether a passenger survived the Titanic disaster.

The project focuses on using passenger information such as **age, gender, passenger class, fare, and family-related features** to make survival predictions.

## Objective

The main objective is to develop and evaluate a classification model that can predict passenger survival based on the available features.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit Learn

## Machine Learning Process

The project covers:

* Data exploration
* Data preprocessing
* Feature selection
* Train test splitting
* Model training
* Making predictions
* Model evaluation
* Confusion matrix and classification metrics

## Project Outcome

This project demonstrates how classification algorithms can be applied to a real world dataset to make predictions and evaluate model performance.

It also provides practical experience with the complete machine learning workflow, from preparing the data to evaluating the final model.
